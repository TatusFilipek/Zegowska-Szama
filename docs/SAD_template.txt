System class architecture

User - information about the user

Role - users role (contains their permissions)

Settings - users settings

Product - information about the product (note: the price will have to get re-fetched from the database and is read-only)

Order - information about the order (user, items, etc)

Item - what gets processed at the checkout (contains product metadata & quantity)
